ДЗ №1 — Классификация уровней ожирения (Obesity Levels)

Задача — многоклассовая классификация (7 классов ожирения).

Датасет
Obesity Levels — 2111 строк, 17 признаков + целевая переменная NObeyesdad (7 классов: от Insufficient_Weight до Obesity_Type_III).

Почему выбран этот датасет: содержит смесь числовых, бинарных, порядковых и номинальных признаков. Датасет преимущественно синтетический (~23% реальных ответов опроса, остальное сгенерировано через SMOTE для балансировки классов), отсутствие пропусков в данных.

Гипотезы:
L2-регуляризация (Ridge) даст более высокий F1 macro, чем L1 (Lasso), так как в данных нет сильно избыточных признаков, которые стоило бы полностью занулять.
L1-регуляризация занулит коэффициенты редких one-hot dummy-переменных (например, MTRANS с низкой частотой встречаемости), но не тронет Weight и Height.
ElasticNet с промежуточным l1_ratio даст результат не хуже отдельно L1 или L2, объединяя устойчивость Ridge и разреженность Lasso.
Ordinal-кодирование CAEC/CALC даст результат не хуже one-hot кодирования при меньшем числе признаков.
F1 macro и F1 weighted будут близки друг к другу, так как классы в датасете сбалансированы искусственно через SMOTE.
Отбор топ-10 признаков через SelectKBest не ухудшит F1 по сравнению с полным набором признаков.
Что сделано
EDA: распределения признаков, корреляционная матрица, боксплоты по классам, проверка пропусков (не обнаружены), проверка выбросов, анализ связи категориальных признаков с целевой переменной (crosstab, хи-квадрат).
Подготовка данных: кодирование бинарных признаков (LabelEncoder), два параллельных варианта кодирования CAEC/CALC/MTRANS — Ordinal (20 признаков) и One-Hot (26 признаков) — для прямого сравнения подходов.
Модели: логистическая регрессия с тремя видами регуляризации — L2 (Ridge), L1 (Lasso), ElasticNet — на обоих вариантах датасета (итого 6 моделей).
Кросс-валидация: StratifiedKFold(n_splits=5).
Подбор гиперпараметров: GridSearchCV по C (и l1_ratio для ElasticNet), метрика f1_macro.
Отбор признаков: SelectKBest (ANOVA F-test) + анализ зануления коэффициентов L1 как встроенный метод отбора.
Метрики: Accuracy, F1 macro/weighted, ROC-AUC (OvR), Log Loss, Cohen's Kappa, classification report, confusion matrix.

Изначально L2/L1 обучались на solver='liblinear' (только режим One-vs-Rest), а ElasticNet — на solver='saga' (режим multinomial/softmax). Это давало некорректно заниженный результат для L2/L1 (~0.78 F1 macro). После перевода всех моделей на единый solver='saga' (multinomial) результаты L2/L1 выросли до ~0.95-0.96 и стали сопоставимы с ElasticNet — сравнение моделей приведено ниже.

По классам: крайние по тяжести классы (Insufficient_Weight, Obesity_Type_I/III) классифицируются практически безошибочно (precision/recall 0.97–1.00). Основные ошибки сосредоточены между соседними классами — Overweight_Level_I (precision 0.90) периодически путается с Normal_Weight и Overweight_Level_II из-за отсутствия резкой физической границы между этими категориями.

Выводы по гипотезам

1. L2 vs L1 (Ridge лучше Lasso) — не подтвердилась. На Ordinal-датасете L2 и L1 показали идентичный результат (0.954 у обеих). На One-Hot датасете L1 оказалась лучше L2 (0.963 против 0.957). Гипотеза была сформулирована в обратную сторону: там, где разница вообще проявилась, лидировала регуляризация L1, а не L2.

2. L1 зануляет редкие dummy-признаки, не трогая Weight/Height — подтвердилась. L1 на One-Hot датасете обнулила 49 из 182 коэффициентов (26.9%). Полностью занулённый признак — CALC_Always (редкая категория употребления алкоголя). Сильнее всего урезаны также MTRANS_Bike (обнулён в 5 из 7 классов), MTRANS_Walking и MTRANS_Motorbike (по 4 из 7) — редкие способы передвижения. При этом Weight и Height не были обнулены ни в одном из 7 классов ни разу, оставаясь основой предсказания.

3. ElasticNet не хуже L1/L2 — частично подтвердилась. На Ordinal ElasticNet показала лучший результат среди всех моделей (0.969). Но на One-Hot ElasticNet (0.956) оказалась немного хуже L1 (0.963) — то есть "гарантированного" преимущества ElasticNet нет, результат зависит от способа кодирования признаков.

4. Ordinal не хуже One-Hot при меньшем числе признаков — подтвердилась. Ordinal-датасет (20 признаков) дал лучший общий результат проекта (ElasticNet, 0.969), используя на 6 признаков меньше, чем One-Hot (26 признаков). Разница между лучшими результатами каждого датасета — менее 0.01, что говорит о сопоставимом качестве при более компактном представлении данных.

5. F1 macro ≈ F1 weighted — подтвердилась. Во всех 6 запусках разница между F1 macro и F1 weighted не превышала 0.001-0.002 — модель работает равномерно по всем 7 классам, что подтверждает эффективность SMOTE-балансировки, заложенной авторами датасета.

6. SelectKBest (топ-10) не ухудшит F1 macro— не подтвердилась. Ограничение до 10 признаков через SelectKBest дало существенное падение качества: F1 macro упал с 0.954 до 0.778 на Ordinal и с 0.957 до 0.791 на One-Hot (падение >15 п.п.). Это заметно опровергает гипотезу и говорит о том, что предсказательная сила в этой задаче распределена по существенно большему числу признаков, чем топ-10 по univariate ANOVA-критерию — в отличие от "мягкого" отбора через L1-регуляризацию (пункт 2), который зануляет признаки куда более консервативно и без такой потери качества.
