# Классификация уровня ожирения

Многоклассовая классификация уровня ожирения (7 классов) по анкетным данным: пол, возраст, рост, вес, пищевые привычки, физическая активность, транспорт.
Проект сравнивает регуляризации логистической регрессии, способы кодирования, отбор признаков и нелинейные модели. Каждый вывод проверяется по кросс-валидации с учётом разброса между фолдами.

**Ноутбук:** [`Obesity_Levels.ipynb`](Obesity_Levels.ipynb)

## Главные результаты

| | CV F1 macro |
|---|---|
| Дерево решений на одном признаке BMI | 0.948 ± 0.010 |
| Логистическая регрессия (L1, multinomial) | 0.958 ± 0.011 |
| Градиентный бустинг + BMI | **0.986 ± 0.004** |
| Случайный лес + BMI | **0.986 ± 0.008** |
| Итоговая модель (бустинг + BMI) на отложенном тесте | **0.983** |
| Без роста и веса, только образ жизни (случайный лес) | 0.850 ± 0.011, вероятно завышено (см. ограничения) |

1. **Класс почти полностью определяется индексом массы тела.** Одно дерево на BMI = Weight / Height² даёт F1 = 0.948. Рост сам по себе бесполезен (F1 = 0.146, уровень случайного угадывания), но вместе с весом задаёт BMI. Признаки образа жизни добавляют к качеству немного.
2. **В логистической регрессии главный эффект дала схема многоклассовой классификации, а не регуляризация.** Переход от One-vs-Rest (`liblinear`) к multinomial (`saga`) поднимает F1 с ≈ 0.80 до ≈ 0.96.
3. **Тип регуляризации и способ кодирования не влияют на качество**: различия в пределах разброса между фолдами.
4. **Лучшие модели — ансамбли деревьев с признаком BMI.** Их отрыв от логистической регрессии (≈ 0.03) в 3 раза больше разброса между фолдами. Деревьям BMI критически важен (одиночное дерево: 0.882 → 0.967), логистической регрессии — нет. Подбор гиперпараметров не дал прироста сверх разброса между фолдами, поэтому итоговой выбрана более простая модель — бустинг с параметрами по умолчанию. На отложенном тесте она даёт F1 = 0.983, что согласуется с CV-оценкой.
5. **Высокое качество без роста и веса объясняется артефактами датасета, а не образом жизни.** Obesity_Type_II почти целиком мужской (295 из 297), Obesity_Type_III почти целиком женский (323 из 324). У 31–62% строк анкетные ответы дробные — следы синтетической генерации. Линейная модель на тех же признаках даёт лишь 0.548.

## Данные

[UCI: Estimation of obesity levels based on eating habits and physical condition](https://archive.ics.uci.edu/dataset/544/estimation+of+obesity+levels+based+on+eating+habits+and+physical+condition):
2111 анкет, 16 признаков, целевая переменная `NObeyesdad` — от `Insufficient_Weight` до `Obesity_Type_III`.
24 полных дубликата удалены до разбиения на train и test (осталось 2087 строк). 77% объектов исходного датасета сгенерированы синтетически (SMOTE).

## Методика

- Стратифицированное разбиение train / test (80 / 20); все сравнения — 5-fold стратифицированная кросс-валидация на одних и тех же фолдах.
- Разница между моделями считается значимой, только если она больше стандартного отклонения F1 по фолдам.
- У всех сравниваемых логистических регрессий одинаковые solver и `max_iter`; сходимость проверяется по `n_iter_`, предупреждения не отключаются. Проверяется, что лучший `C` не на краю сетки.
- Масштабирование и отбор признаков — внутри `Pipeline`, чтобы на кросс-валидации они обучались только на train-фолде.
- Метрика — F1 macro: важно одинаково хорошее качество на всех классах.

## Что ещё показал анализ

- **L1 даёт лучше откалиброванные вероятности** (log loss 0.133 против 0.17–0.18 у L2 и ElasticNet) и зануляет признаки редких категорий (`CALC_Always`, `MTRANS_Bike`, `MTRANS_Motorbike`) и `SMOKE`.
- **Оптимальная регуляризация слабая** (L2: C = 1500): данных достаточно, признаков мало.
- **Одномерный отбор признаков (ANOVA) не видит взаимодействий**: у роста F = 29 против 1554 у веса, хотя в паре с весом рост — второй по важности признак. Совместные методы (RFE, L1) этой проблемы не имеют.
- **Самые трудные классы — Overweight_Level_I и Overweight_Level_II.** Граница между ними (BMI ≈ 27) задана авторами датасета и не совпадает со стандартными порогами ВОЗ.

## Ограничения

- Большая часть датасета синтетическая, поэтому высокие метрики, скорее всего, переоценивают качество на реальных анкетах. Синтетика оставляет следы: дробные ответы на анкетные вопросы с целыми вариантами (31–62% строк по FCVC, NCP, FAF, TUE, CH2O) и почти полное совпадение пола с классами Obesity_Type_II и III.
- Метка фактически выставлена по BMI, поэтому задача в основном сводится к восстановлению формулы по росту и весу.
- Гиперпараметры ансамблей подбирались случайным поиском по той же кросс-валидации, поэтому CV-оценка после подбора немного оптимистична; независимая оценка итоговой модели — отложенный тест.
